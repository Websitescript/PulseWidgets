# Pulse Widgets

Animated clock and calendar home-screen widgets for Android (Realme / ColorOS tested target, minSdk 29).

Widgets: Clock 1x1, 1x2, 2x1, 2x2, 4x2, 4x4. Calendar 1x1, 2x1, 2x2, 4x2, 4x4.

## Build
- Push to GitHub: Actions builds `app-debug.apk` (artifact `PulseWidgets-debug`).
- Or open in Android Studio, or run `./gradlew assembleDebug`.

## Use
Long-press home screen, Widgets, Pulse Widgets. The app lets you change theme, week start and toggle animations.
